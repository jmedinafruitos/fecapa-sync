# fecapa-sync

Llibreria i CLI de codi obert per llegir calendaris i actes d'hoquei patins de la
FECAPA (Federació Catalana de Patinatge), independent de qualsevol club.

> **Estat:** en construcció. Vegeu [`docs/PLAN.md`](docs/PLAN.md).

## English

Open-source, club-agnostic TypeScript library and CLI to read FECAPA roller hockey
fixtures and match reports. When FECAPA/SIDGAD changes its data source, anyone can
contribute a fix. Work in progress — see [`docs/PLAN.md`](docs/PLAN.md).
